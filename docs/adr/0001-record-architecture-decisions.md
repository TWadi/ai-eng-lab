# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-08

## Context

Decisions about this project were made in conversations and pull requests and were hard to find later.

## Decision

Keep short Architecture Decision Records in `docs/adr/`: one file per decision, numbered, never rewritten. A later ADR supersedes an earlier one instead.

## Consequences

New contributors can see why things are the way they are. Changing a decision means writing a new ADR.
